# Project Brief

## Project Overview
This is a Conversational AI Platform built with Next.js, TypeScript, and Tailwind CSS. The platform is designed to manage AI agents, phone numbers, and conversations, with features for call history tracking, agent configuration, and knowledge base management.

## Core Requirements
- Modern web application development
- Type-safe development with TypeScript
- Responsive design with Tailwind CSS
- Component-based architecture
- Next.js framework for server-side rendering and routing
- AI agent management system
- Call history tracking and analytics
- Phone number management
- Knowledge base integration
- Agent configuration interface

## Technical Stack
- Next.js (React framework)
- TypeScript
- Tailwind CSS
- ESLint for code quality
- PostCSS for CSS processing
- Shadcn UI components
- Theme provider for light/dark mode

## Project Structure
- `/app` - Next.js app directory with pages:
  - Dashboard (main page)
  - Agents management
  - Call history
  - Knowledge base
  - Phone numbers
  - Settings
  - Agent configuration
- `/components` - Reusable UI components
  - UI components (shadcn)
  - Custom components (CallSummary, Charts, etc.)
- `/hooks` - Custom React hooks
- `/lib` - Utility functions and shared code
- Configuration files for TypeScript, ESLint, Tailwind, and Next.js

## Goals
- Build a modern, performant Conversational AI Platform
- Maintain type safety throughout the codebase
- Follow best practices for Next.js development
- Create a maintainable and scalable architecture
- Provide comprehensive AI agent management
- Enable efficient call tracking and analytics
- Support knowledge base integration
- Offer flexible agent configuration

## Scope
The project includes:
1. Dashboard with analytics and metrics
2. AI agent management system
3. Call history tracking
4. Knowledge base management
5. Phone number management
6. Agent configuration interface
7. Settings management
8. Theme support (light/dark mode)
